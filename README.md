# GenAI-Chatbot-with-Persistent-Long-Term-Memory
Built a GenAI chatbot with session-based short-term and summarization-triggered long-term memory in PostgreSQL. Compared raw-storage vs. pgvector embedding retrieval for context recall, and integrated multiple LLM providers (Groq, Ollama, OpenAI). Deployment to Streamlit Cloud/HF Spaces in progress.
